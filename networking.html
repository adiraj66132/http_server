Networking 101

A network is just computers sending bytes to each other. To keep this sane, we split the job into layers. Each layer only talks to the layer above and below it.

LayerJobExamples
ApplicationWhat the programs say to each otherHTTP, DNS, SMTP, FTP
TransportDelivers data to the right program, optionally reliablyTCP, UDP
InternetRoutes packets across networksIP (IPv4, IPv6)
LinkMoves frames on one local wire or radioEthernet, Wi-Fi

Key ideas

  • IP address: the address of a machine, like 192.168.1.20. 127.0.0.1 always means "this computer" (localhost).
  • Port: a number from 0 to 65535 that picks a program on that machine. HTTP defaults to 80, HTTPS to 443. Ports below 1024 need admin rights on Linux, so we use 8080.
  • TCP: reliable, ordered stream of bytes. It does a three-way handshake (SYN, SYN-ACK, ACK) first, and resends lost packets. Web pages use it.
  • UDP: fire-and-forget packets, no guarantees. Good for games and voice.
  • DNS: the phone book. It turns example.com into an IP address.
  • Client / Server: the server waits for connections. The client (your browser) starts them.
  • Socket: the handle your program uses to talk over the network. In C on Unix a socket is a file descriptor, so you can read and write it like a file.
  • Byte order: the network sends numbers big-endian. Use htons() and htonl() to convert before putting a port or address in a struct.

How HTTP Works

HTTP is a plain-text conversation on top of TCP. The client sends a request, the server sends back a response. That's all of it. You can even type it by hand with telnet localhost 8080.

A request

GET /index.html HTTP/1.1\r\n
Host: localhost:8080\r\n
User-Agent: Mozilla/3.0 (Win95; I)\r\n
\r\n

Line 1 is the request line: method, path, version. Then headers, one per line. A blank line (\r\n\r\n) ends the headers.

A response

HTTP/1.1 200 OK\r\n
Content-Type: text/html\r\n
Content-Length: 44\r\n
Connection: close\r\n
\r\n
<html><body><h1>Hello!</h1></body></html>

Status line, headers, blank line, then the body. Content-Length must equal the body size in bytes, or the browser will hang or cut the page off.

Status codes you will use

CodeMeaning
200 OKHere is your page
301 / 302It moved, look at the Location header
400 Bad RequestI could not understand that
403 ForbiddenYou are not allowed
404 Not FoundNo such file
405 Method Not AllowedI only do GET
500 Internal Server ErrorMy bad

The Plan: a server in 8 steps

Every TCP server in C follows the same recipe. Memorize it and you can write one in your sleep.

  1. socket() creates the endpoint. Use AF_INET for IPv4 and SOCK_STREAM for TCP.
  2. setsockopt(SO_REUSEADDR) lets you restart the server right away instead of waiting for "Address already in use" to clear.
  3. Fill in a struct sockaddr_in with the family, the IP (INADDR_ANY means all interfaces) and the port, in network byte order.
  4. bind() attaches the socket to that address and port.
  5. listen() marks it as a server socket. The second argument is the queue length for waiting clients.
  6. accept() blocks until a client connects, then returns a new socket just for that client.
  7. recv() the request, parse it, and send() the response. Always send the headers first, then the body.
  8. close() the client socket and go back to step 6. The loop never ends.

Always check return values. Almost every one of these calls returns -1 on failure, and perror() will tell you why.

The C Code

Save this as server.c. It serves real files from the current folder, handles only GET, and blocks path tricks like ../.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <signal.h>
#include <arpa/inet.h>
#include <netinet/in.h>
#include <sys/socket.h>

#define PORT     8080
#define BUF_SIZE 4096

/* send a whole buffer, even if send() writes only part of it */
static int send_all(int fd, const char *data, size_t len) {
    while (len > 0) {
        ssize_t n = send(fd, data, len, 0);
        if (n <= 0) return -1;
        data += n;
        len  -= (size_t)n;
    }
    return 0;
}

static const char *mime_type(const char *path) {
    const char *dot = strrchr(path, '.');
    if (!dot) return "application/octet-stream";
    if (!strcmp(dot, ".html")) return "text/html";
    if (!strcmp(dot, ".css"))  return "text/css";
    if (!strcmp(dot, ".js"))   return "text/javascript";
    if (!strcmp(dot, ".txt"))  return "text/plain";
    if (!strcmp(dot, ".png"))  return "image/png";
    if (!strcmp(dot, ".jpg"))  return "image/jpeg";
    if (!strcmp(dot, ".gif"))  return "image/gif";
    return "application/octet-stream";
}

static void send_error(int fd, int code, const char *text) {
    char body[128], head[256];
    int bl = snprintf(body, sizeof body,
        "<h1>%d %s</h1>", code, text);
    int hl = snprintf(head, sizeof head,
        "HTTP/1.1 %d %s\r\n"
        "Content-Type: text/html\r\n"
        "Content-Length: %d\r\n"
        "Connection: close\r\n\r\n", code, text, bl);
    send_all(fd, head, (size_t)hl);
    send_all(fd, body, (size_t)bl);
}

static void handle_client(int fd) {
    char req[BUF_SIZE];
    ssize_t n = recv(fd, req, sizeof req - 1, 0);
    if (n <= 0) return;
    req[n] = '\0';

    /* parse the request line: METHOD PATH VERSION */
    char method[16], path[512], version[16];
    if (sscanf(req, "%15s %511s %15s", method, path, version) != 3) {
        send_error(fd, 400, "Bad Request");
        return;
    }
    printf("%s %s\n", method, path);

    if (strcmp(method, "GET") != 0) {
        send_error(fd, 405, "Method Not Allowed");
        return;
    }

    /* security: refuse anything trying to climb out of our folder */
    if (strstr(path, "..") || path[0] != '/') {
        send_error(fd, 403, "Forbidden");
        return;
    }

    /* "/" means index.html; drop any ?query part */
    char *q = strchr(path, '?');
    if (q) *q = '\0';
    if (!strcmp(path, "/")) strcpy(path, "/index.html");

    char file[600];
    snprintf(file, sizeof file, ".%s", path);   /* "./index.html" */

    FILE *f = fopen(file, "rb");
    if (!f) { send_error(fd, 404, "Not Found"); return; }

    fseek(f, 0, SEEK_END);
    long size = ftell(f);
    rewind(f);

    char head[256];
    int hl = snprintf(head, sizeof head,
        "HTTP/1.1 200 OK\r\n"
        "Content-Type: %s\r\n"
        "Content-Length: %ld\r\n"
        "Connection: close\r\n\r\n", mime_type(file), size);
    send_all(fd, head, (size_t)hl);

    char chunk[BUF_SIZE];
    size_t got;
    while ((got = fread(chunk, 1, sizeof chunk, f)) > 0)
        if (send_all(fd, chunk, got) < 0) break;
    fclose(f);
}

int main(void) {
    signal(SIGPIPE, SIG_IGN);   /* don't die if a browser hangs up */

    int server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd < 0) { perror("socket"); return 1; }

    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof opt);

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof addr);
    addr.sin_family      = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    addr.sin_port        = htons(PORT);

    if (bind(server_fd, (struct sockaddr *)&addr, sizeof addr) < 0) {
        perror("bind"); return 1;
    }
    if (listen(server_fd, 10) < 0) { perror("listen"); return 1; }

    printf("Listening on http://localhost:%d/\n", PORT);

    for (;;) {
        int client = accept(server_fd, NULL, NULL);
        if (client < 0) { perror("accept"); continue; }
        handle_client(client);
        close(client);
    }
}

How the pieces fit

  • send_all: send() may write fewer bytes than you asked. Looping until everything is out is not optional.
  • handle_client: reads once, parses the request line with sscanf, checks the method, cleans the path, opens the file and streams it in chunks so big files do not need big memory.
  • Path check: without the .. test, a request for /../../etc/passwd would leak files. This is the classic path traversal bug.
  • Connection: close: keeps things simple. One request per connection, then we hang up.

Compile & Run

$ gcc -Wall -Wextra -O2 -o server server.c
$ echo "<h1>Hello from C!</h1>" > index.html
$ ./server
Listening on http://localhost:8080/

Now open http://localhost:8080/ in a browser. Or test from another terminal:

$ curl -i http://localhost:8080/
$ curl -i http://localhost:8080/nope.html     # 404
$ curl -i -X POST http://localhost:8080/      # 405

Want to see the raw conversation? Try telnet localhost 8080, type GET / HTTP/1.1 and press Enter twice.

Windows users: this code uses POSIX sockets. Use WSL, or port it to Winsock (#include <winsock2.h>, call WSAStartup(), use closesocket()).

Level Up

This server handles one visitor at a time. That is fine for learning, and terrible for a busy site. Things to try next:

  • Concurrency: call fork() after accept() (child handles the client, parent closes it), or spawn a pthread per connection. For serious load, learn poll() or epoll().
  • Read the full request: loop on recv() until you see \r\n\r\n. One recv() can return a partial request.
  • Keep-Alive: reuse a connection for many requests instead of closing every time.
  • More methods: HEAD is easy. POST needs you to read Content-Length bytes of body.
  • Hardening: add read timeouts (SO_RCVTIMEO), cap request sizes, resolve paths with realpath(), and drop privileges if you ever bind port 80.
  • HTTPS: wrap the socket with OpenSSL or mbedTLS. Never roll your own crypto.

Good reading: Beej's Guide to Network Programming (free online), and RFC 9110 / 9112 for the real HTTP rules.
